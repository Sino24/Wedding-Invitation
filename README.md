# Wedding Invitation (React + Vite + TypeScript)

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist (deploy to Vercel / Netlify)

Edit all details (names, dates, venues, maps, photos, music, WhatsApp number) in `src/config.ts`.
Put photos and song in `public/` (see public/README.txt).
